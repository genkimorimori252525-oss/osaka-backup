osaka-backup

A personal backup tool with a single user: its owner. After each session on the owner's own computer, it encrypts the owner's backup (7-Zip, AES-256) and stores it in the owner's own Google Drive with rclone.

It asks Google only for the drive.file scope, so it can see and change only the files it has created itself. It cannot see anything else in the Drive.

It is not offered to anyone else, and it has no other users.

Privacy policy

持ち主ひとりだけが使う、控えの道具です。持ち主の PC で控えを暗号化し、持ち主の Google Drive に置きます。 Google に求める権限は drive.file だけで、この道具が自分で作ったファイルにしか触れません。
