Privacy policy

osaka-backup, last updated 8 November 2026.

Who uses it

Only its owner. The tool is not offered to anyone else.

What it accesses

It requests a single Google scope, https://www.googleapis.com/auth/drive.file. With it, the tool can create files in the owner's Google Drive and read, change or remove only the files it created itself (the owner's encrypted backup archives). It does not access any other file, and it does not request email, contacts, calendar or any other Google data.

Where the data goes

The backups are encrypted on the owner's computer before they are sent, and they stay in the owner's own Google Drive. Nothing is sent to the author, to any other person or to any third party. The tool has no server of its own, no analytics and no advertising. This site sets no cookies.

Keeping and removing data

The owner decides how long backups are kept and can remove them in Google Drive at any time. Access can be withdrawn at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
